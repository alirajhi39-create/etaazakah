# منصة درس «إيتاء الزكاة» — العروس الابتدائية

منصة تعليمية تفاعلية متكاملة لمادة الدراسات الإسلامية (الصف الثالث الابتدائي)،
المعلم: **علي عبدالله راجحي** — المدرسة: **العروس الابتدائية**.

> الواجهة مبنية بـ Next.js (App Router) + React 19 + Tailwind CSS، بخطوط **Cairo** و **Tajawal** وتصميم **RTL** بالكامل.
> الواجهة الخلفية عبارة عن Serverless Route Handlers متوافقة مع **Vercel**، وقاعدة البيانات **PostgreSQL** (تعمل مع **Neon** عبر `DATABASE_URL`) باستخدام **Drizzle ORM**.

## الصفحات

| المسار | الوصف |
| --- | --- |
| `/` | بوابة الطالب: الدخول بالاسم/الفصل، استئناف التقدم، ثم الدرس التفاعلي (١٠ شرائح) وشهادة الإنجاز |
| `/teacher` | لوحة تحكم المعلم: التقارير، إدارة الفصول، تعديل وتثبيت الأسماء، مكتبة الأصوات، الطباعة، التشخيص |
| تبويب «واجهة API والتشخيص» | داخل لوحة المعلم فقط بعد تسجيل الدخول (بدون صفحة عامة) |

## محتوى الدرس (الدرس السادس — صفحات ٢٠–٢٢)

| # | الشريحة | المحتوى من الكتاب | الاستراتيجية |
| --- | --- | --- | --- |
| ١ | التهيئة | الدرس السادس: إيتاء الزكاة + أهداف الدرس | التهيئة المشوّقة والعصف الذهني |
| ٢ | معنى إيتاء الزكاة | «إخراج جزءٍ محدَّدٍ من المال، وإعطاؤه المستحقين كالفقراء والمساكين، تقرّبًا إلى الله» | العرض المباشر والتعلم البصري |
| ٣ | الدليل على وجوب الزكاة | ﴿وَأَقِيمُوا الصَّلَاةَ وَآتُوا الزَّكَاةَ وَأَطِيعُوا الرَّسُولَ لَعَلَّكُمْ تُرْحَمُونَ﴾ (النور: ٥٦) | ترتيب كلمات الآية + اختيار |
| ٤ | فضل الزكاة | ﴿خُذْ مِنْ أَمْوَالِهِمْ صَدَقَةً تُطَهِّرُهُمْ وَتُزَكِّيهِم بِهَا﴾ (التوبة: ١٠٣) | التعلم بالاكتشاف |
| ٥ | الإخلاص والمتابعة | «الزكاة عبادة يجب فيها الإخلاص لله تعالى وحده… والمتابعة لسنة النبي ﷺ» | التصنيف |
| ٦ | إضاءة | «منع الزكاة من أسباب حلول العقوبات، ونزع البركات، وانقطاع الأمطار» + صور | التعلم بالصور وتحليل المواقف |
| ٧ | ادّخار المال | «أي جمعه وحفظه للمستقبل» + كتابة ٣ طرق للادّخار وإخراج الزكاة | التعلم التعاوني والتعلم بالعمل |
| ٨ | التقويم | ٣ أسئلة صفحة ٢٢ مع إجابة نموذجية وتقييم ذاتي | التقويم التكويني الكتابي |
| ٩ | الاختبار التفاعلي | ٧ أسئلة تُحفظ درجتها للمعلم | استذكار وتقويم محاسَب |
| ١٠ | الخلاصة | خلاصة الدرس + تأمّل + شهادة إنجاز قابلة للطباعة | التعلم التأملي والختام |

## قاعدة البيانات

- `lesson_progress`: `student_id` (unique)، `student_name`، `class_name`، `current_slide`، `max_slide`،
  `quiz_score`، `quiz_total`، `activities` (**JSONB**)، `completed`، `visits`، `last_seen_at`.
- `teacher_names`: تثبيت الاسم والفصل من المعلم؛ لا يستطيع الطالب تغييرهما بعد التثبيت.
- `lesson_sounds`: `sound_key` (unique)، `label`، `mime_type`، `file_size`، `data` (**BYTEA**) — بحد **4MB** لكل ملف.

تطبيع الفصول تلقائيًا إلى الفصلين **3/أ** و **3/ب**: `3أ` / `٣ / أ` / `3-A` / `الصف الثالث أ` ← `3/أ`، و`3ب` / `ثالث ب` / `3B` ← `3/ب`.

```bash
npx drizzle-kit push --config drizzle.config.json   # تطبيق المخطط
```

## واجهة البرمجة

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `POST` | `/api/progress` | حفظ/تحديث تقدم الطالب |
| `GET` | `/api/progress?studentId=…` | استئناف التقدم |
| `GET` | `/api/progress?name=…&className=…` | استئناف بالاسم والفصل |
| `GET` | `/api/progress?all=true` | تقرير المعلم الشامل |
| `GET` | `/api/progress?diagnose=true` | وضع تشخيصي |
| `PATCH` | `/api/progress` | تعديل/تثبيت الاسم والفصل (`x-teacher-passcode`) |
| `DELETE` | `/api/progress?studentId=…` | حذف السجل (`x-teacher-passcode`) |
| `GET` | `/api/sounds` | قائمة الأصوات وخاناتها |
| `GET` | `/api/sounds?key=…` | استرجاع الصوت (`ETag` + `Cache-Control` + `304`) |
| `POST` | `/api/sounds` | رفع صوت (multipart أو base64) بحد 4MB |
| `DELETE` | `/api/sounds?key=…` | حذف الصوت |
| `GET` | `/api/teacher/auth` | التحقق من رمز المعلم |
| `GET` | `/api/health` | فحص صحة الاتصال بقاعدة البيانات |

جميع المسارات تدعم **CORS** كاملًا (`Access-Control-Allow-Origin: *` + `OPTIONS`).

## متغيرات البيئة

```env
DATABASE_URL=postgresql://user:password@host/db?sslmode=require   # Neon
TEACHER_PASSCODE=139613   # اختياري: يُضاف إلى الرمز الأساسي المضمّن؛ لا يظهر الرمز في الواجهة
```

## التشغيل

```bash
npm install
npm run build
npm run start
```

النشر على Vercel: أضف `DATABASE_URL` (Neon) و`TEACHER_PASSCODE` في إعدادات المشروع، ثم انشر — جميع مسارات
`/api/*` تعمل كدوال Serverless تلقائيًا (حد حجم الطلب 4MB يحكمه حد رفع الأصوات).
